## План

### 0.8.0 — Интеграция, надёжность и скорость

Делает форматтер пригодным для CI, pre-commit и редакторов (сейчас умеет только `-w` и stdout) и закаляет его перед стабильным релизом.

- ✅ **`--check`** — режим для CI: ничего не пишет, выходит с кодом ≠0, если файлы не отформатированы.
- ✅ **`--diff`** — показать, что изменилось бы, без записи (unified diff).
- ✅ **stdin → stdout** (`phew -`) — форматирование буфера из редактора по пайпу.
- ✅ **Параллельный обход** директорий (rayon) — обход и форматирование распараллелены, вывод детерминирован.
- ✅ **Round-trip + property-тесты** — идемпотентность, round-trip (вывод ре-парсится в тот же AST) и фаззинг на произвольном вводе в `tests/properties.rs`.
- ✅ **Escape-hatch (файловый)** — игнор-файл `.phewignore` и уважение `.gitignore` при обходе директорий (через крейт `ignore`). Блочный inline-`@phew-ignore` отклонён: regenerate-from-AST не хранит спаны исходника, потребовал бы verbatim-вклейку и рисковал бы идемпотентностью.
- ✅ **PHP 8.x** — `enum`, named args, first-class callable `f(...)`, `match`; атрибуты `#[...]` проходят насквозь.

### 0.9.0 — Рефакторинг под стандарты Rust

Привести существующий код в соответствие с контрактом (`docs/ai/contract.md`) без изменения поведения.

- **Идиомы** — исчерпывающий `match` без catch-all `_`, newtypes (`IndentLevel`, `LineWidth`), `&str`/`Cow` вместо лишних `String`, итераторы вместо ручных циклов.
- **Декомпозиция** — крупные модули (`split.rs`, `indent.rs`, `engine.rs`) и функции > 50 строк разбить на части.
- **Гигиена** — порядок импортов, derive-дефолты, убрать отладочный мусор.
- **Гарантия поведения** — фикстуры и round-trip из 0.8 ловят регрессии; вывод не меняется.

### 0.10.0 — PSR-12 для объявлений классов и функций

Привести объявления `class`/`function` к PSR-12. Сейчас форматтер раскрывает их тела (надёжно и идемпотентно — проверено на замыканиях, heredoc, цепочках, комментариях), но держит K&R-брейсы и оставляет короткие тела методов в одну строку — это половина PSR. Раздел опционален: в view-файлах (основное назначение) объявления классов почти не встречаются, поэтому фича для смешанных `.php`, где разметка соседствует с кодом.

- **Allman-брейсы** — открывающая `{` на новой строке для `class`/`interface`/`trait`/`enum`/`function`/метода (control-структуры `if`/`foreach`/`switch` остаются K&R, как требует PSR).
- **Развёртка тел методов** — короткое `public function f() { return ...; }` разворачивается на отдельные строки; пустая строка между методами.
- **Консистентность `enum`** — привести объявление `enum` (сейчас K&R) к тому же стилю.
- **Гарантия корректности** — round-trip и идемпотентность из 0.8 ловят порчу кода при развёртке тел.
